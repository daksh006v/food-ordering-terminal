# Food Ordering & Billing System — Terminal Application

A terminal-based Food Ordering & Billing System built with TypeScript.

## Features
- Interactive terminal interface
- Customer management (Guest and Member with membership discounts)
- Food menu browsing across categories (Pizza, Burger, Drink, Dessert)
- Cart management (add, remove, update quantities, special instructions)
- Comprehensive bill calculation (subtotal, membership discounts, threshold discount, GST)
- Multiple payment methods (Cash, Card, UPI) with strict type narrowing
- Order status tracking with exhaustive checks
- Full adherence to strict TypeScript standards (no `any`, no classes, no generics)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run in Development
```bash
npm run dev
```

### Build & Run
```bash
npm run build
npm start
```
